# B8A1 – Problem Solving with TypeScript & OOP

This repository contains my solutions for the B8A1 assignment.

## Assignment Overview

The coding tasks cover optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, `keyof`, classes, inheritance, access modifiers, and asynchronous Promises.

## Files

- [solutions.ts](./solutions.ts) – Solutions to all eight programming problems.
- [type-narrowing.md](./type-narrowing.md) – Blog post about Type Narrowing.
- [access-modifiers-oop.md](./access-modifiers-oop.md) – Blog post about OOP access modifiers.

## Run Locally

Install TypeScript if it is not already installed:

```bash
npm install --save-dev typescript
```

Compile the solution:

```bash
npx tsc solutions.ts --target ES2020 --module commonjs --strict
```

The compiler will generate JavaScript output if there are no errors.
